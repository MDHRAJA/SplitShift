# Split Shift

A Godot 4 endless-runner prototype for the **Double** hackathon theme.

Open `project.godot` in Godot, then run the project.

- Use **A/D** or **Left/Right** to change lanes.
- The yellow outline indicates the runner you control.
- The other runner uses a safe, scripted autopilot.
- Watch for the `SHIFT INCOMING` warning: control swaps after two seconds.
